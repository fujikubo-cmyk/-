# スケジュール管理エージェント

Google Apps Script + Gemini API + Google Calendar を使ったチャット型スケジュール管理ツールです。

## 機能

- 💬 **チャット形式** — 自然な日本語で操作
- ➕ **予定の追加** — 「明日14時から会議を追加して」
- 🗑️ **予定の削除** — 「○○の予定を削除して」
- 📋 **予定の一覧** — 「今週の予定を見せて」
- 📅 **前後の予定確認** — 「この日の前後3日間の予定は？」
- ⚡ **クイックアクションボタン** — よく使う操作をワンクリック

## セットアップ

### 1. Google Apps Script プロジェクト作成

1. [script.google.com](https://script.google.com) でプロジェクトを作成
2. `Code.gs` と `Index.html` の内容をコピー
3. `appsscript.json` の内容を「プロジェクトの設定 > マニフェストファイル」に反映

### 2. スクリプトプロパティの設定

「プロジェクトの設定 > スクリプトプロパティ」に以下を追加:

| キー | 値 |
|------|-----|
| `GEMINI_API_KEY` | Google Gemini APIキー |
| `CALENDAR_ID` | 使用するカレンダーID（省略時は `primary`） |

### 3. Webアプリとしてデプロイ

1. 「デプロイ > 新しいデプロイ」
2. 種類: **ウェブアプリ**
3. 実行ユーザー: **自分**
4. アクセス: **自分のみ** or **全員**（用途に合わせて）
5. 「デプロイ」をクリック → URLをコピー

### 4. 動作確認

```
checkSetup()
```
を実行してAPIキーとカレンダー情報が正しく取得できることを確認。

## 使い方の例

```
「明日の14:00から15:30まで「プロジェクト報告会」を追加して」
「今週木曜日の前後2日間の予定を見せて」
「来月の予定を全部教えて」
「ID: xxx の予定を削除して」
「3連休の予定はある？」
```

## カレンダーIDの確認方法

Google カレンダー → 設定 → 対象カレンダー → 「カレンダーの統合」セクション → 「カレンダーID」
